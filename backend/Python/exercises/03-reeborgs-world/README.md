# Reeborg's World

## Qu'est-ce que c'est ?
[Reeborg's World](https://reeborg.ca/) est une plateforme web qui permet de mettre en pratique les notions apprises en Python sous la forme d'un jeu. Pour ce faire il faut fournir du code brut ou des fonctions personnalisées ou natives à l'environnement du site et réaliser le défi proposé.



## Défis réalisés:

Voici une liste de défis que j'ai complétés jusqu'ici dont deux d'entre eux (le labyrinthe et Hurdle 4) sont des exercices fournis dans le cadre du cours [100 Days of Code d'Angela Yu](https://www.udemy.com/course/100-days-of-code/) (Day 6 - Functions & Karel). Pour les essayer, vous trouverez ci-dessous les liens vers chaque défi ainsi que le code utilisé


> Pour essayer une solution : ouvrez le fichier `.py` correspondant, copiez le code, collez-le dans l'éditeur de texte de Reeborg's World, puis cliquez sur "Exécuter".
